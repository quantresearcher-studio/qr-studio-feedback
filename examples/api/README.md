# Focused strategy API examples / API 使用例

- [SymbolMetadataObserver.cs](SymbolMetadataObserver.cs): `QrExamples.SymbolMetadataObserver`; read-only symbol metadata, local timestamps and normalized price levels. 呼値・現地時刻・価格正規化の表示例です。
- [ApiReferenceExamples.cs](ApiReferenceExamples.cs): `QrExamples.ApiReferenceExamples`; callback and order-method syntax. Order snippets are not invoked by callbacks. コールバックと注文 API の構文例です。コールバックは注文例のメソッドを呼びません。

Compile each file separately in a compatible QR Studio package. See the [English guide](../../docs/strategy-api.md) or [日本語ガイド](../../docs/strategy-api.ja.md) for prerequisites and input data.
