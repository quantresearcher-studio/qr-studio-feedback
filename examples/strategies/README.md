# Bundled strategy samples / 同梱ストラテジー例

17 standalone C# strategy files from the M136 / 0.8.0-rc.6 library. Compile one file at a time with a compatible QR Studio package. `manifest.json` records their exact source hashes and strategy type names.

M136 / 0.8.0-rc.6 ライブラリの独立した C# サンプル 17 個です。対応する QR Studio で 1 ファイルずつコンパイルしてください。型名と元のソースハッシュは `manifest.json` にあります。
