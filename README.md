# QR Studio Feedback

[日本語](README.ja.md) · [Website](https://quant-research.org/) · [Documentation](https://quant-research.org/docs)

Welcome to the public feedback hub for **QuantResearcher Studio (QR Studio)**.
Use this space to report bugs, suggest improvements, ask questions, and share strategy-development tips. English and Japanese are both welcome; you do not need to translate your post.

## Choose where to post

- **Bug reports:** Open an Issue and select **Bug report — English** or **不具合報告 — 日本語**.
- **Feature requests:** Open an Issue and select **Feature request — English** or **機能要望 — 日本語**.
- **Questions and open-ended ideas:** Start a Discussion. Search existing conversations first, and add details to an existing topic when it matches your question.

Please keep each Issue focused on one problem or request. Include the Studio version/build and clear reproduction steps for bugs. If relevant, identify the broker, data feed, and whether you are using backtesting, Paper/simulation, or Live trading.

## Public information only

Issues, Discussions, and attachments here are public. Remove API keys, passwords, tokens, account identifiers, personal information, and private trading records before posting. Share only a short, sanitized log excerpt or screenshot that demonstrates the problem.

For matters that need private handling, use the [contact page](https://quant-research.org/contact) to ask how to share details. Do not include credentials in the initial message.

## Repository scope

This repository contains community documentation and feedback templates. QR Studio's application source code, build artifacts, account settings, and private development history are maintained separately and are not published here.

Feature requests are proposals, not delivery commitments. Maintainers can use Issues to explain decisions, track progress, and identify the release containing a fix.
