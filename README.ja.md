# QR Studio フィードバック

[English](README.md) · [公式サイト](https://quant-research.org/ja) · [ドキュメント](https://quant-research.org/ja/docs)

**QuantResearcher Studio（QR Studio）**の公開フィードバック窓口です。
不具合報告、機能要望、使い方の質問、ストラテジー開発の情報交換にご利用ください。日本語・英語のどちらでも投稿できます。翻訳は不要です。

各ガイドに確認したパッケージ版を記載しています。ドキュメントの更新は、新しいインストーラーの公開告知ではありません。

## 投稿先の選び方

- **不具合報告：** Issues で **不具合報告 — 日本語** または **Bug report — English** を選択してください。
- **機能要望：** Issues で **機能要望 — 日本語** または **Feature request — English** を選択してください。
- **使い方の質問やアイデアの相談：** Discussions をご利用ください。既存の投稿を検索し、同じ内容があればその投稿に情報を追加してください。

1 件の Issue では、1 つの問題または要望を扱ってください。不具合報告には Studio のバージョン・ビルド番号と再現手順を記載してください。関連する場合は、証券会社・データフィード・利用モード（バックテスト、Paper／シミュレーション、Live）も記載してください。

## 公開してよい情報だけを投稿してください

Issue、Discussion、添付ファイルはすべて公開されます。API キー、パスワード、トークン、口座を特定できる情報、個人情報、非公開の取引記録を削除してから投稿してください。問題の確認に必要な範囲のログ抜粋やスクリーンショットのみを共有してください。

非公開での対応が必要な場合は、[お問い合わせページ](https://quant-research.org/contact)で情報の共有方法をご相談ください。最初のメッセージに認証情報を含めないでください。

## このリポジトリの範囲

このリポジトリには、コミュニティ向けの案内、公開ストラテジー API サンプル、合成データによる CLI 手順、フィードバック用テンプレートを置きます。QR Studio 本体・エンジンの実装、ビルド成果物、口座設定、非公開の開発履歴は別途管理し、ここでは公開しません。

機能要望の受付は、実装や提供時期の確約ではありません。対応方針、進捗、修正を含むリリースなどは、各 Issue で確認できます。
